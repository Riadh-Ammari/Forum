# Forum - Discussion Platform in C

We developed a **discussion forum** using the **C programming language**, combining our technical skills with a shared passion for technology.

## 💡 About the Project

This project offered us the opportunity to explore **advanced programming concepts** while strengthening our ability to work **collaboratively**. From initial design to full implementation, every step contributed to gaining new skills and a deeper understanding of technical challenges.

It was not just a coding exercise—it was a meaningful learning experience that allowed us to apply procedural programming principles to a real-world use case.

## 🚀 What We Built

- 🔐 Secure user registration and login system  
- 📝 Ability to create discussion threads  
- 💬 Replying to existing topics  
- 📁 Persistent data storage using text files  
- 🧭 Simple, console-based interface for interaction  

## 🛠️ Tech Stack

- **Language**: C (Procedural Programming)  
- **Data Handling**: File I/O (users, posts, threads)  
- **Compilation**: GCC or any C-compatible compiler  
- **Recommended Environment**: Unix/Linux or Windows (MinGW)
